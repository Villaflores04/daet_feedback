# High-end design brief — DAET Pulse

Written so the UI is a civic product, not a student CRUD template.

## What high-end means here

Not more gradients. It means:

1. One place in the world. Daet / Pacific edge / pineapple-gold civic desk — not generic purple SaaS.
2. Two speeds. Visitors move in three taps. Officers get a quiet desk, not another marketing page.
3. Editorial type. Big serif headlines (Fraunces), calm sans body (Manrope). Numbers are display-scale.
4. Restraint. Gold is a signal, not a fill. Glass panels sit on ink. Grain is almost invisible.
5. No tourist account chrome. Name modal is a ritual, not a signup form.

## Palette

- ink `#07131c` — page ground
- tide `#0c2433` — cards / photos underlay
- sand `#f4efe4` — body text
- gold `#e8c572` — focus, CTA, rank
- foam `#d7f3ea` — positive sentiment
- coral `#e07a5f` — negative / delete

## Flows

- Name gate: "Before you speak" — short, no email, Continue in gold.
- Review: rating orbs + emoji row + one publish button.
- Pulse: three stats, sentiment bars, ranked spots, latest voices.
- Desk: password only at /admin, then spots / comments. No Admin in the public header.

## Refused

- Tailwind default indigo
- Inter everywhere
- Forcing tourists through Supabase Auth
- A dashboard that looks like an analytics SaaS login
